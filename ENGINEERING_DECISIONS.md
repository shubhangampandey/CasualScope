# Engineering decisions

1. **Real SDK spans, explicitly instrumented HTTP.** Separate SDK resources give each of eight actual service listeners its own identity while retaining a lightweight process model. AsyncLocalStorage and explicit W3C propagation make context behavior testable. Eight listeners do not imply eight process failure domains.
2. **An official protobuf contract.** Vendored Apache-licensed OpenTelemetry v1.9.0 definitions avoid a made-up trace JSON format and avoid a network requirement at runtime. Only OTLP/HTTP protobuf traces are claimed. gzip support was verified against a real Collector.
3. **Two storage modes with explicit identity.** PostgreSQL + Prisma metadata and ClickHouse telemetry are the deployment path. Docker was missing on the host, so persistent local SQLite made real pipeline and security verification possible. The UI states the adapter. No PostgreSQL/ClickHouse success is inferred from SQLite tests.
4. **Stable pinned Prisma.** Registry `latest` resolved to a Prisma 8 release candidate during implementation. Prisma 6.19.3 was checked and deliberately pinned; a major-version adapter migration adds no value to this local system. The lockfile captures all other resolved versions.
5. **JSONB metadata first.** Composite workspace/kind/id documents minimize duplicate storage logic and let local/full adapters share a contract. Typed domain records and mutation validation exist, but foreign keys, richer uniqueness constraints, email lookup indexes and normalized lifecycle tables remain scaling work.
6. **Analysis outside request handling.** A five-second worker evaluates bounded persisted windows; user analysis is rate-limited. This keeps ordinary request paths separate from repeated analytical computation. A single process is still vulnerable to sufficiently expensive Node-side analysis; worker-thread isolation and database-native windows are next steps.
7. **Causality requires more than correlation.** Parent context supports structural order; generic links support association. Cross-host timestamp sorting is visualization, not proof. Ranking scores order candidates; they are not confidence probabilities. No automatic experimentally-verified-cause badge is emitted from one run.
8. **Labels are separate.** Fault labels reside in a different table and are only read after predictions are stored. Healthy baseline selection belongs to the experiment controller; the inference function receives observations, not expected answers. Early live verification found that a preceding time window could contain another fault. Explicit source-run selection fixed the experimental comparison boundary without tuning ranking weights to a desired answer.
9. **Missing telemetry reduces certainty.** Deduplication prevents repeated batches from inflating counts. Missing parents, sampling warnings, sparse windows and clock skew remain visible. A failure outside the captured graph remains an explicit candidate.
10. **Bounded synthetic faults.** Queues, concurrency, arrival rates and durations have finite limits. The resource saturation scenario creates bounded waiting rather than exhausting host RAM or CPU. Reset intentionally discards outstanding synthetic notifications; this queue is not a production job broker.
11. **Optional Gemini.** The official SDK receives only ≤20 small anomaly summaries after an explicit consent action. It does not rank, execute tools, control experiments, or modify evidence. Response IDs are checked against the submitted references. Core operation requires no key.
12. **Custom SVG and CSS.** Eight-service investigation graphs and waterfalls benefit from exact coordinates and readable monochrome line treatments. React Flow, D3, a global state library and a separate UI package were not added merely to match a technology checklist. Motion is limited and reduced-motion aware.
13. **No deployment assertion.** Images, migrations, health checks and CI definitions are supplied. External hosting, production TLS, secret provisioning, actual backup restores and database load validation remain explicit deployment work.
